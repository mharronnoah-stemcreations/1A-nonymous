# 1A-nonymous | NGL-Style Toad Messaging Website

A vibrant, anonymous messaging web application inspired by **NGL.link**, featuring **Toad** as the interactive mascot, the lush **Princess Peach's Castle** background, a **pixel-art speech bubble** as the message input area, and real-time integration with **Supabase**.

---

## Features

- **Mario & Toad Aesthetic**:
  - Full-screen Princess Peach's Castle background (`mga_imahe/background-sm.webp`).
  - Interactive **Toad Mascot** (`mga_imahe/toad.webp`) that waves, floats, jumps on tap, and shares secret-keeper voicelines.
  - Floating ambient glowing sky particles.
- **Pixel Bubble Input**:
  - Uses the custom pixel bubble (`mga_imahe/bubble.webp`) directly as the responsive textarea frame.
  - Character counter (`0 / 300`) with visual threshold warnings.
  - Transparent custom-padded input for pixel-perfect alignment.
- **NGL Dice Prompt Shuffler**:
  - Shuffle between 15+ prompts with rolling animations and sound.
- **Retro 8-bit Synthesized Sound**:
  - Custom Web Audio API synthesizer (no external audio files needed):
    - Authentic Mario Coin sound on message submission.
    - Jump sound on tapping Toad.
    - Dice click on shuffling prompts.
    - Mute/Unmute toggle with local state persistence.
- **Celebration Confetti**:
  - Multi-directional celebration burst on message delivery.
- **Toad's Inbox**:
  - Live inbox view fetching real-time messages from Supabase.
  - Relative timestamps ("Just now", "5m ago", "1h ago").
  - Quick copy button for messages.
  - **Instagram Story Card Generator**: Generates an NGL-style card ready to screenshot or copy for social media stories.
- **Dual-Sync Storage**:
  - Inserts directly to Supabase with an automatic local storage fallback so messages are never lost even before table migration.

## How to Run Locally

### Option 1: Open Directly in Browser
You can simply open `index.html` directly in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Using Node / npm
```bash
npm start
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Using Python
```bash
python -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000).

## Supabase Database Setup

Your Supabase project link:  
`https://ujhisqxsixqrqpjjeaaj.supabase.co`

To enable live cloud storage for incoming messages:

1. Open your **[Supabase SQL Editor](https://supabase.com/dashboard/project/ujhisqxsixqrqpjjeaaj/sql)**.
2. Paste the contents of `supabase_setup.sql`:

```sql
-- 1. Create the messages table
create table if not exists public.messages (
  id bigint generated by default as identity primary key,
  content text not null,
  prompt text default 'Send me anonymous messages!',
  recipient text default 'toad',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Enable Row Level Security (RLS)
alter table public.messages enable row level security;

-- 3. Policy: Allow anyone (anonymous users) to send/insert messages
create policy "Allow anonymous message inserts"
  on public.messages
  for insert
  with check (true);

-- 4. Policy: Allow anyone to read messages (for the public Toad inbox)
create policy "Allow public message reads"
  on public.messages
  for select
  using (true);
```
3. Click **Run**.
4. Your messages will now stream directly to your Supabase database table in real time.
